# GNOSIS Security: site institucional

Site estático (HTML + CSS + JS), sem build.

- `index.html`: página principal
- `privacidade.html`: política de privacidade (LGPD)
- `.well-known/security.txt`: contato para reportar vulnerabilidades (renovar o campo `Expires` antes de 10/11/2027)
- `assets/site.css`, `assets/site.js`: estilos e comportamento
- `assets/`: imagens, logo e selos de certificação
- `staticwebapp.config.json`: cabeçalhos de segurança (Azure Static Web Apps)

Branch `novo-site`: nova versão em revisão. `main`: versão no ar.
